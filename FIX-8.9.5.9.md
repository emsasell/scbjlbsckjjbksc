# MegaMine 8.9.5.9 — отдельная история обновлений

- История обновлений вынесена в отдельный раздел админ-панели.
- Текущая версия/описание/дата больше не создают запись истории автоматически.
- Для истории есть отдельные действия: создать, изменить и удалить.
- Каждая запись хранит: версию, название, описание и дату.
- Дата истории валидируется как обычная дата `YYYY-MM-DD` и не переводится в UTC.
- При временной ошибке БД API настроек больше не подменяет сохранённые данные дефолтами `1.0.0`, поэтому интерфейс не должен «сбрасываться» из-за неудачного запроса.
